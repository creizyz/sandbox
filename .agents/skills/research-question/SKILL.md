# Research a technical question

1. Identify the decision the answer should inform, the relevant versions and workload, and what
   evidence would change that decision.
2. Choose sources suited to the claim. Use specifications for guarantees, primary implementation
   documentation or source for tool behavior, and workload-matched measurements for performance.
   Follow [research and evidence](../../../guidelines/03-research-and-evidence.md).
3. Compare conditions before reconciling results. Relate the evidence to Sandbox's current code
   or [project context](../../../docs/README.md) where applicable. Separate source claims, local
   observations, and conclusions.
4. Answer with traceable sources, applicability limits, and any remaining uncertainty that could
   affect the decision.
