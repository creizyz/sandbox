# Architecture decision records

Use this index for significant Sandbox architecture decisions affecting the app, library, tests,
or benchmarks. Record the context, options considered, rationale, consequences, and status.
See the [project layout](../README.md#project-layout) and the
[architecture guideline](../../guidelines/04-architecture-and-design.md).

Numbers are sequential within this folder. Status **Proposed** identifies a design for review;
it does not describe implemented behavior or authorize implementation.
